# ADR 0005：惰性面、极小国家与镜头跟随

- 状态：已采纳
- 日期：2026-02（本轮）
- 相关：`docs/adr/0004`（次区域与下钻）、`docs/adr/0003`（世界几何源）

## 背景

本轮处理六件事，其中三件共享同一个根因，另外三件是镜头与反馈的行为调整：

1. **下钻后空白区域仍有交互**（缺陷）。用户报告：下钻到大洲/次区域后，鼠标悬停在看起来空白的区域上，会高亮一个「看不见的国家」，点击还会跳到它的上级区域。
2. **移除梵蒂冈**。
3. **新增全局设置「忽略面积极小的国家」**：开启后小国不出题、也无法交互。
4. **错误回滚每次答错都要标红**，且红显时长延长到 1.5 秒。
5. **世界输入模式加入自动跟随**，缩放倍率与国家面积成反比。
6. **所有模式答错后自动把镜头平移到答错的地点**，但不改变缩放。

## 决策

### 1. 惰性面：保留几何但不响应

缺陷的根因不在事件处理器，而在**渲染数据**：`buildWorldRegionData` 对当前范围之外的国面执行 `continue`，即**不登记外观**。ECharts 的 geo 组件对未登记的面会回落到 geo 层默认样式（本项目里是透明），于是这些面「看不见」，但它们的几何**依然参与命中测试**，且 `geo.emphasis.areaColor`（悬停遮罩）照常生效。所以：

- 悬停 → 高亮一个看不见的国家；
- 点击 → 命中该面的 `name` → 解析出 iso → `drillFromWorldNation(该国的洲, ...)` → 跳到**它所属的**大洲/次区域。

修法是把它们登记为 **`silent: true` 的透明面**，而不是跳过。已核对 ECharts 实现：`var silent = regionModel.get('silent', true); silent != null && (el.silent = silent)`，且事件派发前有 `if (el && el.silent) return`。因此 `silent` region **既不派发鼠标事件、也不做 emphasis 高亮**，正好是「存在但完全无交互」。

同时在事件回调里再加一层 `worldFaceInteractive(name)` 守护，覆盖 tooltip 与 name→iso 回传的兜底。判定逻辑抽到 `src/map/worldFaces.ts` 纯函数，由 `worldFaces.test.ts` 锁死——这是本轮最容易回归的一条。

**空白点击行为不变**：落在惰性面上的点击与落在真正空白上的点击语义相同（等价于 `onBlankClick`），有下钻层级时退回上一层。用户确认要保留上一轮定下的**空白返回**。

### 2. 梵蒂冈：移出答题池，保留为装饰面

梵蒂冈从 `countries.json` 移除（195 → 194），在 `world_v2.topojson` 中被重新分类为**装饰面**。选择保留灰面而不是删除几何，原因有实证：意大利在该处有 **1 个内部环（空洞）**（已用射线法验证梵蒂冈质心落在其中），删掉梵蒂冈面会在意大利上留下可见缺口。保留灰面既填住缺口，又通过既有装饰面机制满足「不出题 + 不可交互」。

保留灰面不违反「装饰面不得持有答题池内的 iso」——梵蒂冈已不在池中，管线的这条断言仍然成立。

### 3. 极小国家：按视觉面积定线，构建期现算

「极小」的判定用**经纬度平面上的 shoelace 面积（度²）**，而不是球面真实面积：要求是「地图上很难发现」，这与屏幕上看到的大小一致；球面面积会把高纬度国家折算得过小。

阈值取「面积 ≤ 马绍尔群岛」。这条线落在**天然断崖**上——下一个国家科摩罗的面积是它的 1.7 倍（度²：STP 0.077 → COM 0.132）。阈值只硬编码锚点 iso（`MHL`）一个值，清单由 `scripts/build-subregions.mjs` 从 `world_area.json` 现算，并带断言 F/G（必须是答题国、必须含锚点、必须小于池的 1/3）。梵蒂冈移出后清单为 6 国：MCO、MDV、MHL、NRU、SMR、TUV。

面积表 `world_area.json` 由世界数据管线产出；该管线需联网，**不在 `npm run build` 链路内**。因此 `build-subregions.mjs` 在该文件缺失时只警告、不失败，前端拿到空清单等价于「没有极小国家」，功能降级但不阻塞构建。

### 4. 该设置是全局的，且不裁剪排行榜

做成**全局设置**（`Settings.ignoreTinyCountries`，沿用既有的 `china-admin-settings-v1` 键，新增字段，`loadSettings` 显式归一为布尔以兼容旧档）而非每模式设置。生效集合放在 `src/tinyCountries.ts` 的模块级单例，由 `appController.applyTinyCountrySetting()` 一次写入，供渲染器与三模式的出题池共用——两条路径必须同时生效，否则会出现「能出题却点不动」或「灰显却仍在池里」。

**不裁剪排行榜范围**：排名池始终按全部答题国，开与不开该设置的用户在同一张榜上可比。这是刻意的取舍——若随设置收缩排名池，就需要新增一种**范围哨兵**，而哨兵是已写入 D1 的持久化契约（见 ADR 0001/0004），代价远大于收益。

### 5. 错误回滚：标红与计分解耦

`this.red` 原本承担**临时高亮**的职责（回滚计时器到点就删），永久进度由 `results`/`fail` 记录。原实现把 `red.add(q)` 放在 `if (firstWrong)` 块内，于是**只有第一次答错会标红**。

修法是把 `red.add(q)` 移出该块（每次答错都加），而 `rollbackCounted` 仍只决定永久进度——标红回答「刚才这次错了」，进度红格回答「这题错过」，两者刻意解耦。时长 700 → **1500 ms**（700ms 实测「还没看清就没了」）。

### 6. 镜头：世界跟随按面积反比，答错跟随只平移

两者是不同触发、不同缩放语义，必须分开：

- **世界跟随**（出题时）：缩放与**国家面积成反比**。用 **log 插值**把面积映射到 `[1.6, 9]`——面积跨 6 个数量级，线性插值会让九成国家挤在同一档。端点直接返回常量，避免线性插值在 `k=1` 处算出 `1.5999999999999996` 而破坏「区间闭包」这条可断言性质。
- **答错跟随**（答错时，所有模式）：只把镜头平移到**正确答案**位置，**保持当前缩放**。目标是自反馈，不应把用户的视角缩放强行拉走。

「答错的地点」取**正确答案**的位置（而非用户点错的位置）：这是记忆练习的纠错目的，点错的位置用户本来就看得见。

## 后果

- 新增数据文件：`public/data/world_area.json`（194 国度² 面积）、`public/data/tiny_countries.json`（极小国家清单）。
- `AppData` 新增 `countryArea`；`Settings` 新增 `ignoreTinyCountries`。两者都是**新增**，不改动既有字段与哨兵。
- 答题国从 195 变为 **194**，欧洲 44 → 43、南欧 14 → 13；SEO 落地页、`index.html` 的 meta/JSON-LD、README/CONTEXT/DESIGN 中的计数已同步（均由数据派生或已逐处核对）。
- 装饰面 49 → **50**（梵蒂冈）。装饰面**数量仍不是契约**。
- 新增可测单元：`src/map/worldFaces.ts`、`src/tinyCountries.ts`、`worldFollowZoom`（已导出）。测试 150 → 175。
- 新增运行时验收脚本 `scripts/verify-round2.mjs`（22 项，headless Edge）+ `scripts/shot-round2.mjs`（截图）。**注意本机 `C:\Program Files (x86)\Google\Chrome\...` 是 Chrome 38，不支持 ES module**，headless 下页面主 bundle 根本不执行——必须用 Edge，否则会得到「应用没启动」的假象。文件特意命名为 `verify-*` 而非 `probe-*`，因为 `.gitignore` 排除 `probe-*.mjs`（一次性的性能/几何探针不入库），而本脚本要长期防回归。
- `src/probe.ts` 仅在 `?probe=1` 时动态加载（独立 chunk 3.2KB，普通用户不拉取），生产路径不受影响。

## 未采纳的方案

- **范围外的面直接不画（隐藏几何）**：正是本缺陷的成因——不可见但可命中、且带 emphasis 遮罩。
- **删除梵蒂冈几何**：会在意大利上留下内部环缺口。
- **用球面真实面积判定「极小」**：与「地图上很难发现」的实际体验不符。
- **把该设置做成每模式设置**，或**随设置收缩排行榜池**：前者导致模式间不一致，后者要动持久化的范围哨兵契约。
- **答错时也改变缩放**：与「世界跟随」语义重叠，且会打断用户的视角。
- **用源码文本嗅探（`answer.toString()`）验证「每次标红」**：压缩后必然失效，改为驱动真实行为断言可观测状态。
