# 困难档只对「孤悬/极小」单位放宽吸附容差，但仍然不给提示

困难档的口径是「**完全不给任何吸附预告**」：拖动中目标不亮、手里那块不加描边、点选→点放的幽灵预览同样不亮，只有松手后真正吸上才看得见结果。目的是不允许靠提示"撞运气"（2026-09-14 用户口径）。

问题是这条口径与**几何现实**冲突。有两类单位在困难档里不是"难"，而是"没道理"：

- **极小**：澳门在 1x 下约 0.5×1.2 像素、香港约 5×4.7 像素——边界看不清，也就无从判断"快到了"；
- **孤悬**：台湾、海南与大陆隔海（各自以福建/广东为兜底邻居），世界档的日本、澳大利亚、新西兰、冰岛等岛国同理——没有相邻陆块做参照。

困难档的容差只有 5px，对这两类单位意味着"必须几乎精确命中"才能吸上，而玩家手上没有任何反馈。

因此引入一条**例外**：困难档下，这类单位**还是单独一片时**吸附容差放宽到 **15px**；一旦它并进任何一组，立刻回到 5px。判定取两方中**较宽**的那一方（拖广东靠近海南、或拖海南靠近广东都是 15px）。**提示照旧一个都不给**——放宽的是"手感门槛"，不是"难度本身"。

认定规则取三者并集（判定见 `src/puzzle/specialUnits.ts`）：

1. **面积极小**：碎片面积 ≤ 0.1614 度²（≈2000 km²，中国侧正好只圈住港澳，上海 0.7758 远在阈值外）；
2. **孤悬**：在**当前范围**里没有陆地邻居（复用 `buildPuzzleGraph` 的 `landConnected`）；
3. **另算岛国名单**：英国、爱尔兰、印尼、多米尼加、海地、巴布亚新几内亚、东帝汶、文莱 8 个——它们彼此或与大陆有陆地邻国，第 2 条捞不到。

实测：省级全国名单正好是**港澳台海南** 4 个；世界全国 **51/194**（39 个无陆地邻国 + 4 个欧洲微国家 + 名单 8 个）。

**Status**: accepted

**Consequences**:

- 第 3 条是**全项目唯一一处"按国名/地区名硬编码"的玩法口径**。它是本次改动最脆的一环：换几何源、调整大洲/次区域归属、或修改 `neighbors` 数据都不会让它报错，只会让名单悄悄变错。故 `src/puzzle/specialUnits.test.ts` 用**真实数据**把名单逐项钉住（省级全国 4 个精确相等、世界档 51 个、以及"大陆国家不入选"），改数据时测试会先响。
- 面积判据与「卡槽供应顺序」的**极小**判据共用同一个阈值，但**不是同一个集合**：供应顺序只看面积（海岛不算），因为"排到最后"解决的是"从卡槽拿出来就找不到了"，只对真的看不清的片有意义（台湾 47×48px 看得清）。
- 世界档这条规则覆盖了 26% 的碎片（51/194），困难档在世界范围整体变松。这是为可用性付出的代价；若日后要收窄，最直接的做法是给面积判据加一条上限（把澳大利亚、新西兰、日本、马达加斯加这类大岛国排除），规则会从两段变三段。
- 与"给提示"彻底解耦：将来若想让简单档也放宽，只需改 `PuzzleSnapOptions.relaxedPx` 的赋值处（`src/modes/puzzle.ts` 的 `ensureState`），判定逻辑无需改动。
