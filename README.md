# 🗺️ 中国行政区记忆

纯前端小项目：帮助记忆中国行政区（精确到地级市）。输入"黔南"这种简称即可让地图上对应区域变色，支持省略"自治州""土家族"等限定词与错别字容错。

## 一键启动

双击 **`一键启动.bat`**（首次运行会自动安装依赖并打开浏览器），或手动执行：

```bash
npm install
npm run dev
```

然后访问 http://localhost:5173

> 需要 Node.js ≥ 18（推荐 LTS）：https://nodejs.org

## 四种模式

| 模式 | 玩法 |
|---|---|
| **自由模式** | 点击地图区域或输入地名（回车确认）标记绿色；输入错误只清空输入框、状态不变。无时间限制、无固定顺序，进度自动保存在浏览器（localStorage） |
| **自测模式** | 随机起点标蓝 → 转红提问；答对变绿，下一个蓝点 = 与上一个答对绿点**相邻**的地级单位（优先同省，BFS 扩张）；答错保持红色。倒计时默认关闭，可在设置中开启 |
| **挑战模式** | 随机标红一个地级市，输入正确变绿并立即出下一题；答错或超时标红跳过。默认每题 10 秒，设置中可调 |
| **记忆模式** | 全图显示所有地级市名称（标签在区域中心），纯浏览 |

## 通用操作

- **颜色**：🟢 绿=已完成/正确（变绿即显示白底绿框地名标签）｜🔵 蓝=当前题目｜🔴 红=答错标记（显示白底红框标签）｜⚪ 灰=未涉及
- **地名标签**：白底标签（边框/字体颜色随状态：绿=答对、红=答错、深灰=浏览）；放大字号显示在区域中心
- **缩放分级**：缩得太小（zoom < 2.5）时**不显示任何标签**防止扎堆，放大到一定程度后自动显示地级标签
- **省界**：加粗线条显示省级边界（同一地图视图内渲染，无独立图层）
- **缩放**：滚轮自由缩放、拖拽平移（两个图层同步）
- **省份下钻**：顶栏选择省份，或在地图上**双击**任意区域 → 其他地方消失，仅保留该省并自动居中；点"返回全国"恢复
- **输入匹配（无下拉联想）**：输入"黔南布依族苗族自治州""黔南州""黔南"均可命中"黔南"；错别字（编辑距离≤2）可容错；输入省名（如"贵州省"）直接下钻该省；输入"海南"优先命中"海南藏族自治州"（地级优先）
- 记忆单位：333 个地级行政区 + 北京/上海/天津/重庆/香港/澳门/台湾 7 个整体单位（共 340 个）；省直辖县级区域（海南直辖县、仙桃、济源、兵团城市等 30 个）作为灰色填充面补齐地图空白，不参与记忆统计

## 数据说明

- 边界数据来自[阿里云 DataV.GeoAtlas](https://geodataviewer.com/datasets/boundaries/chinese-admin-boundaries/)（免费、无 Key），已打包进 `public/data/`，运行时不依赖网络
- 重新生成数据（需网络，可加 `--no-simplify` 关闭几何简化）：

```bash
npm run build:data
```

- 邻接关系（自测模式 BFS 扩张用）由构建脚本用 turf 自动计算，存在 `units.json` 的 `neighbors` 字段

## 项目结构

```
scripts/build-data.mjs   # 数据管线：下载 → 合并 → 邻接 → 简化 → 输出
public/data/             # 构建产物：china_units.geojson + units.json
src/
  matcher.ts             # 地名规范化 + 模糊匹配 + 消歧
  map/renderer.ts        # ECharts 渲染：着色/标签/下钻/高亮动画
  store.ts               # 自由模式进度 + 设置（localStorage）
  modes/                 # 自由 / 自测(BFS) / 挑战 / 记忆 四种模式
  ui/                    # 搜索框、倒计时、统计面板、设置面板
  main.ts                # 装配入口
```
