# 🗺️ 地图记忆

纯前端小项目：帮助记忆**中国行政区**（精确到地级市）与**世界国家**。输入“黔南”这种简称即可让地图上对应区域变色，支持省略“自治州”“土家族”等限定词与错别字容错。

支持逐层下钻缩小记忆范围：中国侧 全国 → 省；世界侧 全世界 → 大洲 → 次区域。点地图空白处退回上一层。

## 一键启动

双击 **`一键启动.bat`**（首次运行会自动安装依赖并打开浏览器），或手动执行：

```bash
npm install
npm run dev
```

然后访问 http://localhost:5173

> 需要 Node.js ≥ 18（推荐 LTS）：https://nodejs.org

## 五种模式

| 模式 | 玩法 |
|---|---|
| **输入模式** | 键盘输入地名作答。答对变绿、答错变红并计入熟练度；原自测模式的相邻扩张和可选倒计时保持不变。世界/省级全国档还可用「国名/首都」「中文/英文」「省名/简称」切换题面口径（见下方**取名口径**） |
| **挑战模式** | 键盘输入地名作答，随机出题并倒计时；答对立即进入下一题，答错或超时显示答案后继续。 |
| **拼图模式** | **先选范围、再拼图**：进入时仍是完整地图，可切换「世界/省级/市级」并下钻（世界 → 大洲 → 次区域（大洋洲不细分）；省级/市级 → 某省的地级市）、点空白退回上一层，确定范围后点「开始」。开局后地图消失、画布清空：左侧三个玻璃态卡槽各装一片，拖出即真实大小、可放任意位置（**1x 与地图 1x 同比例**，缩放 0.8–28x）；面积小的碎片压在面积大的之上（北京/天津陷在河北的环里）；相邻两片靠近正确位置约 15px 就自动精准拼合、此后整组一起拖；该范围的全部碎片拼成一整块即获胜（计时；世界全国与全国市级两档按已拼个数进排行榜） |
| **点击模式** | 顶部显示随机地名，点击地图对应区域作答；答对变绿，答错时正确答案变红；按当前全国或省份范围出题，不使用自动跟随。世界/省级全国档可用「国名/首都」「中文/英文」「省名/简称」切换题面与地图标签的口径（见下方**取名口径**） |
| **熟练度分析** | 按输入、挑战和点击模式累计的分数给地图分层着色；三档地图默认常显地名标签；悬停城市可查看正确/错误次数，右侧显示各省掌握情况；左下角「设置」可隐藏地图标签 |

## 通用操作

- **取名口径**（输入 / 点击模式，2026-09）：顶部在「顺序/随机/错题」右边还有几组分段按钮，决定**考什么名字、用什么语言**。
  - **世界档**：**国名 / 首都** 切换考国名还是考首都名；**中文 / 英文** 切换题面与地图标签的语言（输入框提示与实际输入都跟着变；界面文案仍是中文）。两者可组合，例如「首都 + 英文」＝题面显示 `Tokyo`、地图标签显示英文首都名。
  - **省级全国**：**省名 / 简称** —— 简称档按单字简称出题（如「沪」），地图标签也显示简称。省级档没有中英文切换。
  - 判题与题面同源：国名档只认国名、首都档只认首都名、简称档只认简称（含 蜀/黔/滇/秦/陇 等官方并存写法）；中英文是同一个名字的两种写法，两种都算对。
  - 这三组按钮只在**对应的全国视图**、且**未开始答题**时出现；开始后整组收起（避免当前题的题面与答案对不上）。选择按模式分别记住。

- **答题统计**：正确次数使分数 +1，错误次数使分数 -1；跳过不计入统计。
- **熟练度色阶与阶梯**：分界线为 **-10 / -5 / -1 / 0 / +1 / +5 / +10**，即糟糕 ≤-10、较差 -9~-5、陌生 -4~-1、一般 0、初识 +1~+4、熟练 +5~+9、炉火纯青 ≥+10（地级/省级/世界三档分析共用同一套断点）；地图上对应深红/中红/浅红/原色/浅绿/中绿/深绿。
- **未开始时显示地图标签**（2026-09：「自由模式」下线，浏览能力并入前四个模式）：点击 / 输入 / 无尽闯关在**未开始**的浏览阶段显示全部地名（世界=国名、省级全国=省名、其余=地级市名，任何缩放倍率都显示），点「开始」后自动收起、**结束（结算卡片出现 / 答完 / 重置）后自动恢复**。开始答题后已作答单位的绿/红标签**不受影响**（那是答题反馈）。开关在导航栏「设置 → 地图标签」里，默认开；老用户若在旧自由模式里关过标签，升级后保持关闭。拼图模式的名称由难度档控制（见下），不受这个开关影响。
- **按钮区布局（未开始）**（2026-09）：地图左上角的按钮在**未开始**时按固定顺序纵向排列 —— 顺序/题面口径行（顺序·随机·错题、国名/首都、中文/英文…）→ 全世界/各大洲 → 次区域 → **世界/省级/市级** → **重置**。**重置永远独占按钮区最后一行**，且与大洲/粒度行左对齐；点「开始」后这些行收起、`跳过 · 暂停 · 重置` 回到同一行 —— **开始后的布局与以前完全一致**。熟练度分析没有"开始"概念，它的粒度行与重置同行，不参与这条规则。世界档未开始时层级最多：大洲行、次区域行、粒度行、重置各占一行。
- **省界**：加粗线条显示省级边界（同一地图视图内渲染，无独立图层）；**全局设置**里可分别调整地级市边界 / 省级边界 / 世界边界的深浅（浅灰/灰/深灰）。
- **黑夜/白天模式**：顶栏「设置」左侧的按钮一键切换主题（按钮文案显示点击后会切到的模式），选择立即持久化。
- **设置项开关**：设置面板里的开关为 DSH 风格（36×20 轨道 + 16px 圆形滑块）；关闭时滑块在左（暗主题白点、明主题深灰点），打开时整条轨道填成反相实色（暗主题全白、**明主题深灰 —— 与分段按钮选中态同色，不再是纯黑**）。全局设置与每模式设置浮层共用同一套样式，改一处即可。
- **结算卡片的「提交成绩」**：白字**灰**底（与分段按钮选中态同一个深灰），不用绿底白字 —— 后者对比度只有 1.92:1，低于验收脚本 3.5:1 的客观体检线。其余主按钮（发帖 / 保存 / 登录 / 继续）保持品牌绿。
- **缩放**：滚轮自由缩放、拖拽平移（两个图层同步）。
- **省份下钻**：在地图上双击任意区域进入该省（拼图模式的选范围阶段也能下钻；世界档无省级下钻）；空白区域点击返回全国。**唯一层级的省级单位不下钻**：京津沪渝（直辖市）与港澳台各自只有一个下级单位（就是它自己），钻进去只会得到「1 个单位的练习 / 1 片拼图」，因此**所有模式**下点击它们都只在原地给一行提示，不切换范围。
- **世界下钻**：世界粒度下未开始答题时，单击/双击国家逐层下钻（全世界 → 大洲 → 次区域）；重选大洲用「全世界/各大洲」分段按钮，次区域用其下方的分区行（首项「全亚洲」等表示不限次区域）。**大洋洲不再细分次区域**（澳新/美拉尼西亚/密克罗尼西亚/波利尼西亚四个分区仍是数据的一部分，只是所有模式都不再下钻到它们：大洋洲仍可选、可点国家进入，但点进去不再变小）。答题开始后不再下钻。
- **空白返回**：点地图空白处退回上一层范围（次区域→大洲→全世界；省→全国），分段按钮高亮同步回退。答题进行中不生效（提示「请重置后返回全国」）。下钻后**其他洲的国家面属于「惰性面」**——存在几何但不显示、不响应悬停、点击等同于点空白，不会跳到该国所属的大洲。
- **忽略面积极小的国家**（全局设置）：开启后面积过小、难以发现的国家（当前 6 个：摩纳哥、马尔代夫、马绍尔群岛、瑙鲁、圣马力诺、图瓦卢）不再出题、地图上灰显且完全无交互。判定线为「面积 ≤ 马绍尔群岛」，按视觉面积（度²）在构建期现算。该设置**只影响练习**，排行榜范围不变。
- **镜头跟随**：世界粒度出题时自动跟随，缩放与国家面积成反比（`A−B·ln(面积)`，夹到 3–28x：立陶宛约 11x、法国约 8x、俄罗斯约 3x）；任何模式答错后镜头平移到**正确答案**位置，但不改变当前缩放。**跟随不会再无条件把目标放到正中**：目标贴在当前地图范围边缘时（如大兴安岭、俄罗斯北部、下钻到宁夏这种小省），镜头只推到"屏幕不出现大片空白、且目标离屏幕边不少于视口短边 10%"为止，因此目标会偏离正中；若正确答案本来就已经在视口里看得舒服，答错跟随干脆不动镜头。
- **拼图模式操作**：进模式先**选范围**（地图还在，可切粒度 / 下钻，点空白退回上一层），「开始」后地图隐藏、只留该范围的碎片；左侧三个卡槽随拖随补，**按住拖拽**或**点卡槽→点画布**都能放置，靠近正确位置自动磁吸成组，全部拼成一整块即获胜。**缩放 1x 与地图 1x 同比例（0.8–28x）**、上下层按**组总面积**排序、磁吸容差**简单 10px / 困难 5px**（困难档不给任何吸附预告）、「已拼」按拼合进度计、「重置」回到开始卡片。**完整规则**（选范围与下钻语义、几何固定用 40% 档的理由、吸附方向与连锁、邻接连通与台/琼特例、各按钮语义）见 **[docs/specs/puzzle-operations.md](docs/specs/puzzle-operations.md)**。
- **拼图排行榜**：只有**世界全国（194 国）**与**全国市级（340 个地级单位）**两个范围可提交，按**已拼个数**排名、同数按用时；**已拼 ≥ 2** 才算成绩。中途终止与拼完都能提交。细则见 **[同一篇](docs/specs/puzzle-operations.md#排行榜与提交门槛)**。
- **装饰面不参与答题**：省直辖县级市、兵团城市、南海诸岛（`units.json` 里 `decorative: true` 的 33 个面）只用于补齐地图空白与参与邻接计算，**不参与匹配/统计/测试**，因此答题池是 340 个真实地级单位（此前后处理把它们洗成了可答题单位、池子涨到 372，本轮修正）。
- **顺序出题（输入模式）**：严格按照广度优先搜索出题，只在地图**当前范围**内扩张——下钻到大洲/次区域后不会出到范围外的国家；前沿队列保证不会出现「周围都答完了、中间还剩一个」的空洞。
- **测验收起排行榜**：开始测验自动收起排行榜侧栏，结算或重置后自动展开（属于临时 UI 状态，不覆盖你手动设定的开合偏好）。
- **输入匹配（无下拉联想）**：输入“黔南布依族苗族自治州”“黔南州”“黔南”均可命中“黔南”；错别字（编辑距离≤2）可容错；输入省名（如“贵州省”）直接下钻该省。
- **URL 深链**：支持 `?g=world&c=AS&s=EAS`（世界+亚洲+东亚）、`?g=city&p=440000`（市级+广东）、`?g=province`。非法参数静默忽略。
- 中国记忆单位：333 个地级行政区 + 北京/上海/天津/重庆/香港/澳门/台湾 7 个整体单位（共 340 个）；省直辖县级区域作为灰色填充面补齐地图空白，不参与答题统计。
- 世界记忆单位：194 个答题国家；属地/南极等为装饰面，不参与答题。答题国按 6 大洲、23 个次区域划分。梵蒂冈已移出答题池，其面保留为装饰面（它嵌在意大利的一个内部环里，删掉会在意大利上留下缺口）。

## 数据说明

- 地级/省级边界数据来自[阿里云 DataV.GeoAtlas](https://geodataviewer.com/datasets/boundaries/chinese-admin-boundaries/)（免费、无 Key），已打包进 `public/data/`，运行时不依赖网络
- 重新生成数据（需网络，可加 `--no-simplify` 关闭几何简化）：

```bash
npm run build:data
```

- 世界边界数据来自 [Natural Earth 10m admin_0 countries 中国视角变体 `_chn`](https://www.naturalearthdata.com/)（公有领域），经 `scripts/fetch-world-data-v2.mjs` 简化为 `public/data/world_v2.topojson`
- 国家的**英文名与首都名**（「国名/首都」「中文/英文」分段按钮用）来自同一套 Natural Earth v5.1.2 数据（国家英文名取 `ne_10m_admin_0_countries_chn` 的 `NAME_EN`，首都取 `ne_10m_populated_places` 里 `ADM0CAP=1` 的据点），由 `scripts/fetch-world-names.mjs` 生成为 `public/data/world_names.json`（194 条，与 `countries.json` 的 iso 一一对应，有单测断言）。繁体字与台湾译名按大陆通用译名人工校订，逐条理由写在该脚本的 `NAME_OVERRIDES` 里
  - 中位线段 0.163°（1000px 世界图下约 0.45px），旧档为 0.733°（约 2.04px），精细度提升 4.5 倍
  - **必须用 `_chn` 变体**：标准版把**藏南**划给印度（实测 8 个藏南城镇旧档归中国 8/8、NE50 标准版 4/8、`_chn` 8/8）。该变体由 Natural Earth 官方完成边界处理，本管线无需任何多边形布尔运算
  - 答题国 iso 集合与 `countries.json` 逐字相同（194 个，零重复）；装饰面数量随源变化（现 50 个，含不再作为答题国的梵蒂冈），故**不作为契约**——契约是「装饰面不得持有答题池内的 iso」
  - 中国在世界图上仍是**一个合并面**（含台湾/香港/澳门，`_chn` 变体已预合并台湾），并由旧档回补 5 个最南端南海岛礁多边形（曾母暗沙约 3.4°N）
  - 领土口径有语义断言守护：藏南 8 个真实城镇必须全落在中国面内、中国面最南纬度必须低于 5°N
  - 重新生成：`node scripts/fetch-world-data-v2.mjs`
  - 旧档 `world.geojson` 与旧管线 `scripts/fetch-world-data.mjs` **保留在库中但不再加载**（回滚路径：把 `src/data.ts` 的 `world_v2.topojson` 换回 `world.geojson`）
- 邻接关系（输入模式 BFS 扩张用）由构建脚本用 turf 自动计算，存在 `units.json` 的 `neighbors` 字段；国家邻接在 `countries.json` 的 `neighbors`
- 世界地图对比图（人工验收用）：`node scripts/shot-world-compare.mjs` → `shot-world/`（5 组，同投影对比新旧两个几何源，每组上=旧档、下=新档）

## 运行时验收探针

本轮的多数改动是**运行时行为**（ECharts 的 `silent` region、镜头动画、红显时长），单测只能覆盖抽出来的纯函数，故另有一个真实浏览器验收脚本：

```bash
npm run build
node scripts/verify-round2.mjs     # 38 项：世界跟随缩放、答错跟随、顺序出题、侧栏收起等
node scripts/verify-round3.mjs     # 54 项：主题按钮、设置面板/开关样式、未开始的浏览标签（清空/复现）与按钮纵向布局、游客登录入口、发帖草稿、标签默认显示
node scripts/verify-puzzle.mjs     # 75 项：拼图两阶段 × 三粒度的选范围/下钻/空白返回/开始清空/1x 与地图一致/组面积层级/拖拽/磁吸方向/分档容差/难度提示/暂停/获胜/重置/拼图排行榜与提交门槛（真实鼠标与点击事件）
node scripts/verify-naming.mjs     # 22 项：世界档「国名/首都」+「中文/英文」、省级全国「省名/简称」的题面与画布标签
node scripts/shot-follow-clamp.mjs # 跟随钳制的 9 张边界样例截图
node scripts/shot-round2.mjs       # 出验收截图到 docs/shots/
```

- **必须用 Edge**：本机 `C:\Program Files (x86)\Google\Chrome\...` 是 **Chrome 38**，不支持 ES module，headless 下主 bundle 根本不执行，会得到「应用没启动」的假象。
- 探针代码在 `src/probe/`（按域拆成 internals / map / quiz / puzzle / ui 五个模块），仅当 URL 带 `?probe=1` 时动态加载（独立 chunk，普通用户不拉取）。私有状态一律通过生产类自带的诊断视图读取（`AppController.diagnostics()` 等），因此探针目录**没有反射式强转**：成员改名会让 `tsc` 报错而不是让断言静默失效，理由见 [ADR 0007](docs/adr/0007-probe-reads-internals-via-typed-diagnostics-view.md)。
- 验收覆盖：空白区无交互（事件层 + 渲染层双重断言）、梵蒂冈不在池内、极小国家开关、错误回滚每次标红 + 1500ms、世界跟随缩放单调性、答错跟随不改缩放、跟随钳制（取景边界/倍率下限）、UI 收尾（按钮回滚、开关样式、标签默认显示、未开始显示标签/开始后清空/结算与重置后复现、全局开关生效、游客点右上角直接进登录、未登录发帖草稿不丢）、拼图模式（选范围阶段的地图/**省级与市级两种下钻都真的收窄范围**/空白返回、拼图 1x 与地图 1x 实测比对、困难档无提示、开始后清空画布、拖拽、磁吸、面积层级、难度收起与重现、暂停、三个粒度各自的获胜、「拼图完成」标题、重置回开始卡片、拼图排行榜与提交门槛）、唯一层级省级单位不下钻、大洋洲不再细分次区域。
- 说明：`scripts/` 下其余 `probe-*.mjs` / `diag-*.mjs` 为一次性探针，按 `.gitignore` 不入库；本轮这个因为要长期防回归，特意改名 `verify-*` 入库。

## SEO

站点是纯客户端渲染的 SPA，`dist/index.html` 不含任何地名，爬虫拿不到正文。构建时由 `scripts/gen-seo-pages.mjs` 从数据**生成**约 60 个静态落地页（省级/大洲/次区域），使每类地名都可被独立检索到，并通过 URL 参数深链回应用视图。

生成脚本带 6 组断言（slug 全覆盖与唯一、大洲国家清单与次区域映射互为反函数、每国恰属一次区域、每省至少一个真实地级单位、地级总数守恒），保证**落地页内容与应用数据不脱节**——这是"落地页与应用不一致"被判作弊的防线。

另有 `public/robots.txt`、`public/sitemap.xml`（扁平 urlset，百度拒绝索引型）与 `public/404.html`。**404.html 必须存在**：Cloudflare Pages 在项目没有它时按 SPA 处理，把所有未知路径匹配到 `/` 并返回 HTTP 200，于是 robots.txt 与 sitemap 都读不到。本站零客户端路由（全库无 `pushState`/`history`/`popstate`），整个应用只活在 `/`，故加 404.html 不会破坏任何深层链接。

```bash
npm run build:seo   # 只重新生成次区域数据 + 落地页（build 已自动调用）
```
